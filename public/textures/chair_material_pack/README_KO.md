# Chair Material Pack — starter PBR textures

이 파일은 사용자의 원본 7개 GLB를 열어보고 추출한 정확한 재질이 아니라, 공개적으로 확인 가능한 모델 소재와 과거 의자 목록을 기준으로 직접 제작한 **절차적 PBR 시작 재질**입니다. 실물 사진에서 추출한 텍스처라고 주장하지 않습니다.

## 설치
1. ZIP을 풀고 폴더 안의 재질 하위 폴더들을 웹사이트의 `public/textures/`로 복사합니다.
2. `material_manifest.json`을 읽어 각 의자의 실제 mesh 이름에 해당하는 재질만 적용합니다. 자동으로 모든 부품에 강제 적용하지 않습니다.
3. 색상 텍스처는 sRGB, normalGL / roughness는 linear 데이터로 로딩합니다. 일부 GLB mesh는 UV가 없거나 매핑이 올바르지 않을 수 있습니다.
4. 색상이 원본과 다르면 색상맵 대신 normal/roughness만 사용하거나 원본 색상과 맵을 조정합니다.
5. 투명 PC와 크롬은 이미지맵이 아닌 물리 재질 파라미터로, 반드시 좋은 environment map과 함께 표현합니다.

## 주의
- GLB 모델과 실제 상품별 사진이 없으므로 001,003,004,005,007의 정확한 부품 매칭·색상은 검증되지 않았습니다.
- 금속 분체도장도 실제 페인트 피막은 비금속성이므로 mesh material의 metalness는 일반적으로 0으로 설정하는 것이 물리적으로 정확합니다. manifest의 금속 항목 중 도장 표면 metalness는 웹 적용 시 0으로 오버라이드하세요.
- 모델 분해·조립 계층 및 애니메이션을 변경하지 마세요.
- 이 팩은 코드로 생성된 반복 가능한 추정 재질이며 고해상도 실물 사진 스캔 텍스처가 아닙니다.
